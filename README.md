# allbright-care-site

Built output of the Allbright Care website, deployed to the Crazy Domains cPanel host with
cPanel Git Version Control (pull deployment). Source lives in a separate private repository.

- `site/` is `dist/` from a production build (`VITE_SITE_ORIGIN=https://allbrightcare.com.au`).
- `.cpanel.yml` says what the next deployment does. Read it before pressing Deploy.

Everything here is already public on the website itself.
